# Companion ownership

- Own the Electron companion, encrypted local career vault, local MCP transport/tools, conversation skill, document codec/baseline/layout/PDF source, and installer packaging in this repository.
- Website account authentication, checkout, download hosting, pairing UI and signed-device proxy belong to `recruiters-rip-frontend`. Middleware authorizes devices and current paid job-feed access. Do not import sibling repositories or add database/server inference dependencies.
- Preserve app ID `rip.recruiters.companion`, product name `Recruiters.rip Companion`, storage/keychain name `Recruiters Companion`, protocol `recruiters-companion`, and production `device` directory. Never inspect, mutate, reset or migrate a user's actual vault as a test.
- Production defaults to `https://recruiters.rip`. Local-product mode is explicit and isolated. Account connection opens `/settings/provider` with `deviceId`, `publicKey`, and `deviceLabel`; native approval remains mandatory.
- Keep CVs, facts, scores and drafts local. New feed access requires real current membership; unpaid users keep saved data. Never manufacture entitlements or authentication, add local payment fixtures to production, or request provider keys.
- Reasoning belongs to official user-subscription apps. Do not add CI/API inference, model SDKs, automated live candidate scoring, or fallback web-job search. Preserve scoring, decision, evidence, source continuity, and CV review gates.
- `package.json` is the single version source. Generated code/plugins, dependencies, installers, certificates, secrets, vaults and user exports are not source-control inputs. The document source closure and required assets must remain buildable from this clone alone; retain the font license in packaged output.
- Normal maintainer checks: `pnpm install --frozen-lockfile`, `pnpm build`, `pnpm check`, `pnpm test`. Tests may use only temporary synthetic data and must not launch real inference. Run gates only when assigned; workers leave final gates to the integration owner.
- `pnpm package:release` requires real signing/notarization credentials and never publishes. `pnpm package:adhoc` is explicitly unnotarized but uses the production website. Report that limitation; do not claim signing/notarization evidence you have not observed. Installers are hosted through the frontend's configured file path, not invented GitHub download URLs.
