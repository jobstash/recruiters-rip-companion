      Browser extensions
      

      Optional · save jobs and fill forms

      Add a browser extension to save jobs and help fill application forms. Keep Companion open when using it.
      

      

      Chrome extension
      


      1. Choose Open folder here.
      2. In Chrome, open chrome://extensions and turn on Developer mode.
      3. Choose Load unpacked and select the folder that Companion opened.
      4. Open a job ad or application and choose the recruiters.rip toolbar icon. It reads the page.
      

      

      

      

      Firefox extension
      


      1. Choose Open folder here.
      2. In Firefox, open about:debugging → This Firefox → Load Temporary Add-on.
      3. Select manifest.json in the folder that Companion opened.
      4. Open a job ad or application and choose the recruiters.rip toolbar icon. It reads the page.
      You will need to load it again after closing Firefox. If you downloaded a ZIP file instead, unzip it first.

          In your AI app
          

          Keep Companion open. To start from a conversation you already have, send:
          Use recruiters.rip to find jobs that fit my CV. Ask about any missing preferences and explain which roles fit and why.
          New recruiters.rip jobs need a membership. Codex or Claude uses your own account and any required plan, billed separately. A browser extension and extra API key are not needed to review jobs.
          My AI app cannot find recruiters.rip
          Follow Set up in Settings → AI apps, enable recruiters.rip in your AI app when asked, then start a new conversation. If Continue in Codex or Continue in Claude does not open the app, copy the message into it yourself.
          

          

          

          Open your CV and letter
          

          1. Ask your AI to create and save a tailored CV and cover letter for a job.
          2. Open Jobs in Companion and select that job.
          3. Under Job and documents, choose Open CV or Open letter. Check them, then choose Open job to apply.
          The same saved documents are available when you select the job under Applications. Both PDFs are saved together in a folder for the company and job title, named with your name: Your name - CV.pdf and Your name - COVER LETTER.pdf. If they are missing, ask your AI to create and save both PDFs.
          

          

          

          Apply from your browser
          

          Add the extension in Settings → Browser extensions, then keep Companion open.
          1. Open a job ad or application form and choose the recruiters.rip toolbar icon. It reads the page and gets any saved answers ready.
          2. Choose Prepare application. Codex or Claude opens with a request for your CV, introduction and answers. Click Send there, or press Enter in the text window. To change app, use Options in the extension.
          3. When it is ready, click an empty answer box and press ⌘V on Mac or Ctrl+V on Windows and Linux. Show CV shows the file to upload; Copy intro copies your introduction for a cover letter or message box.
          4. Check the form, then submit it yourself.
          Saved answers work without an API key. A job you have already prepared is reused, not written again.
          The extension cannot prepare this page
          • No job found on this page: open the job ad or application form itself, then choose Read page.
          • Choose the job you want to apply for: select a job. It opens in a new tab; choose the toolbar icon there.
          • Companion is not open: open it, then choose Retry. Not installed? Choose Get Companion.
          • Locked: unlock your saved data in Companion, then read the page again.
          • Update Companion: install the update in Settings → Updates, then read the page again.
          • Import your CV: in Me, choose Import CV.
          • Codex or Claude is unavailable: choose the other app under Options, or set it up in Settings → AI apps.
          • Extra form help is unavailable: choose Use saved answers.
          • The job or your saved details changed: choose Refresh answers or Update application.
          

          

          

          Backups
          

          In Settings → Backups, choose Save backup to keep a private copy of your work. To recover one, choose Restore backup, select the file, check the preview and choose Restore profile.
          Restoring replaces your current profile, not your sign-in or API keys. Companion saves the previous profile first; find it in Open backups. Backup files are not password-protected.
          Delete a CV instead
          Open Me → CVs, select the CV, choose Delete CV and confirm. If it was shared with JobStash, that copy must be removed first. If removal fails, the CV stays here so you can try again. Other CVs, applications and backups stay unchanged.
          Use the account that shared it. Stopping CV sharing prevents future uploads; it does not delete a shared copy.
